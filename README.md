# ☕ BrewLite – Đặt đồ uống mobile-first

Đồ án **Assignment 2 – Công nghệ phần mềm** (Trường Đại học Sài Gòn).

Luồng nghiệp vụ: **Xem menu → Chọn tùy chọn → Giỏ hàng → Đặt đơn → Thanh toán → Theo dõi đơn**

Công nghệ bắt buộc: Next.js (mobile-first/PWA) · NestJS · PostgreSQL · Docker.

## Cấu trúc dự kiến

```
brewlite/
├── apps/web     # Next.js
├── apps/api     # NestJS
├── docs/        # yêu cầu, sơ đồ, kiến trúc, sprint
└── tests/       # integration / E2E
```
